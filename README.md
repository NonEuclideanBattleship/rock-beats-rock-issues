# Rock Beats Rock

Public issues board for Rock Beats Rock. 

![alt text](https://github.com/NonEuclideanBattleship/rock-beats-rock-issues/blob/main/01OSfE.png)

A lighthearted calvinball deckbuilder where you compete to have the best rock collection. [Play it here on Itch.io!](https://astraexmachina.itch.io/rock-beats-rock)

Found a bug? Have some suggestions? Look for your issue [here](https://github.com/NonEuclideanBattleship/rock-beats-rock-issues/issues) on the board. [Open a new issue](https://github.com/NonEuclideanBattleship/rock-beats-rock-issues/issues/new) for those that haven't been documented.
